# frontend

Веб-клиент nexoraPoly: одностраничное приложение.

**Стек:** React, Vite, Tailwind CSS, TanStack Query, dnd-kit, date-fns.

## Страницы

| Маршрут | Назначение |
|---|---|
| `/onboarding` | Вход через Telegram и выбор группы |
| `/dashboard` | Главная: пары на сегодня, горящие дедлайны |
| `/schedule` | Расписание: день / неделя |
| `/tasks` | Задания: канбан |
| `/subjects` | Предметы, прогресс, допуск |
| `/groups` | Группы и участники |
| `/notifications` | Уведомления |
| `/settings` | Профиль, тема, уведомления |

Исходный код будет перенесён в эту папку. Инструкции по запуску добавляются вместе с кодом.
