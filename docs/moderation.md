# Модерация платформы

Модераторы следят за порядком на платформе: смотрят статистику, отвечают на обращения студентов и подтверждают преподавателей. Страница — `/moderation` на сайте, пункт «Модерация» в меню виден только модераторам.

## Как выдать роль модератора

Роль выдаётся **только вручную** командой на сервере. Других способов нет намеренно: ни эндпоинта API, ни кнопки на сайте, ни команды бота. Модератор не может назначить другого модератора — для этого нужен доступ к серверу.

Пользователь должен хотя бы раз войти на сайт. Аргумент — его Telegram ID.

```bash
# в поде бэкенда
kubectl -n nexora exec deploy/nexora-backend -- python -m src.cli.moderator add 123456789
kubectl -n nexora exec deploy/nexora-backend -- python -m src.cli.moderator remove 123456789
kubectl -n nexora exec deploy/nexora-backend -- python -m src.cli.moderator list

# локально, из папки backend
python -m src.cli.moderator add 123456789
```

Каждое изменение пишется в журнал аудита (`moderator_granted` / `moderator_revoked`) и видно во вкладке «Журнал».

Узнать Telegram ID: пользователь пишет боту [@userinfobot](https://t.me/userinfobot) или ID есть в таблице `identities` (`provider = 'telegram'`).

## Что на странице модерации

| Вкладка | Что там |
|---|---|
| Статистика | Пользователи (всего, новые за неделю), активные за 7 и 30 дней, группы, задания, уведомления за неделю, открытые обращения, заявки преподавателей; графики активных и новых пользователей за 30 дней |
| Обращения | Сообщения из Настройки → Поддержка. Статусы «новое → в работе → закрыто». Ответ модератора уходит студенту в Telegram и закрывает обращение |
| Преподаватели | Заявки из Настройки → Поддержка → «Я преподаватель». Подтверждение выдаёт роль преподавателя, пользователю приходит уведомление |
| Модераторы | Список модераторов и дата выдачи роли. Только просмотр |
| Журнал | Действия модерации: выдача ролей, ответы, решения по заявкам |

## Как считается активность

На каждый авторизованный запрос id пользователя добавляется в HyperLogLog Redis за текущий день (`active:YYYY-MM-DD`, хранится 35 дней). Это занимает до 12 КБ в день независимо от числа пользователей. Если Redis недоступен, запросы работают как обычно, а активность в статистике будет 0.

## API

Все маршруты `/api/v1/moderation/*` требуют роль модератора, иначе `403`.

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/moderation/stats` | Статистика за 30 дней |
| GET | `/moderation/support?status=new` | Обращения (`new`, `in_progress`, `closed` или все) |
| PATCH | `/moderation/support/{id}` | `{"status": ...}` и/или `{"reply": ...}` — ответ уходит в Telegram |
| GET | `/moderation/teacher-applications?status=pending` | Заявки преподавателей |
| POST | `/moderation/teacher-applications/{id}/approve` · `/reject` | Решение по заявке |
| GET | `/moderation/moderators` | Модераторы (только чтение) |
| GET | `/moderation/audit` | Журнал действий модерации |

Для пользователя:

| Метод | Путь | Что делает |
|---|---|---|
| POST | `/support` | Обращение в поддержку (не больше 5 открытых одновременно) |
| GET | `/support/my` | Свои обращения и ответы |
| POST · GET | `/users/me/teacher-application` | Подать заявку преподавателя / узнать её статус |

`GET /users/me` возвращает `is_moderator` и `is_teacher`. Изменить их через `PATCH /users/me` нельзя — поля игнорируются.
