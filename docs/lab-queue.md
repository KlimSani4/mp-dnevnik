# Очередь на сдачу лабораторных (#62)

Живая очередь на конкретную пару. Основной канал — Telegram-бот (`/queue`), на сайте
раздел «Очереди» (`/queues`, на телефоне — «Ещё» → «Очереди») с теми же данными.

## Роли

| Кто | Что может |
|---|---|
| Староста, заместитель, помощник старосты (подтверждённые) и модератор платформы — «ведущий» | открыть очередь на пару, начать сдачу, отметить «сдал / не сдал / нет на месте», закрыть |
| Подтверждённый участник группы | записаться с номерами ЛР, поменять ЛР, пропустить ход, уйти в конец, выйти, попросить поменяться местами |
| Остальные | ничего, очередь группы не видна |

## Как идёт очередь

1. Ведущий открывает очередь на пару дня: выбирает порядок и сколько ЛР можно сдать за подход (1–5).
   На одну пару в один день — одна незакрытая очередь.
2. **Запись** (`open`). Студенты встают в очередь. Пропуски и обмены уже работают.
3. **Сдача** (`started`). По кнопке «Начать сдачу» порядок выстраивается по режиму, первый
   становится «сдаёт». После отметки ведущего вызывается следующий.
4. **Закрыта** (`closed`). Все незавершённые просьбы об обмене отменяются. На ту же пару можно открыть новую.

## Режимы порядка

| Режим | При старте | Кто записался после старта |
|---|---|---|
| `first_come` — кто раньше записался | порядок не меняется | в конец |
| `random` — случайно при старте | все перемешиваются (`SystemRandom`) | в конец |
| `lab_number` — сначала младшие ЛР | по наименьшему номеру ЛР | на своё место, после всех с тем же номером |
| `debtors` — сначала должники | по числу сданных ЛР по предмету в текущем семестре | на своё место, после всех с тем же числом |

Сортировка стабильная: пропуски и обмены, сделанные во время записи, при старте не теряются
внутри одинакового ключа.

## Действия

- **Пропустить ход** — на одно место назад. Тот, кто сдаёт, тоже может уступить следующему.
- **В конец** — в хвост очереди.
- **Нет на месте** (ведущий) — сдающий уходит в конец, счётчик пропусков +1.
- **Сдал** (ведущий) — в «Предметах» за текущий семестр к сданным прибавляется число ЛР из записи
  (не больше общего числа ЛР, если оно задано).
- **Поменяться местами** — только с тем, кто стоит впереди и ещё ждёт; одна активная просьба на человека.
  Адресату приходит сообщение в Telegram с кнопками «Поменяться / Нет», ответить можно и на сайте.

Сообщений «подходит ваша очередь» нет — это решено сознательно; очередь видна в боте («Обновить»)
и на сайте (обновляется каждые 4 секунды).

## Устройство

- Таблицы `lab_queues`, `lab_queue_entries`, `lab_queue_swaps` (миграция `009_lab_queues`).
- Логика порядка без базы — `backend/src/core/queue_order.py`, сервис — `backend/src/core/services/queue.py`.
- Каждое изменение идёт под `SELECT … FOR UPDATE` строки очереди: одновременные нажатия в боте и на сайте
  не перепутают порядок.
- API: `/api/v1/queues` (список, пары дня, открыть, карточка, `join`, `me`, `skip`, `start`, `close`,
  `entries/{id}/result`, `swaps`). Бот: `backend/src/gateways/telegram/handlers/queue.py`, формат
  `callback_data` описан в начале файла.
