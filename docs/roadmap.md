# Roadmap nexoraPoly

Статусы: ⬜ не начато · 🟨 в работе · ✅ готово. Каждый пункт при взятии в работу оформляется отдельным issue.

## Фаза 0 — Гигиена

| Задача | Статус |
|---|---|
| Привести в порядок репозиторий: структура, документация, шаблоны | 🟨 |
| Убрать тестовые данные (моковые имена) из production-сборки | ⬜ |
| Исправить чекбоксы на главной | ⬜ |
| Исправить перемещение виджетов в задачах | ⬜ |
| Исправить сохранение расписания | ⬜ |
| Отдавать `manifest.json` и `robots.txt` как файлы, а не SPA-fallback | ⬜ |
| Заголовки безопасности: CSP, HSTS, X-Frame-Options | ⬜ |
| Разбить бандл на чанки, lazy-загрузка страниц | ⬜ |
| Продуктовая аналитика | ⬜ |
| CI: сборка и линтеры на каждый PR | ⬜ |
| Переезд на новый домен и хостинг | ⬜ |
