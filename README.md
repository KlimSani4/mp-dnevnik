# 🏫 MosPolitech Dnevnik  
## Единый студенческий дневник

---

### 📘 Описание
**MosPolitech Dnevnik** — система, созданная для упрощения академической жизни студентов и преподавателей.  
Цель — объединить все ключевые функции учебного процесса в одном месте, минимизировав рутину и дублирование данных.

---

### 🎯 Цели проекта
- Централизовать расписание, оценки, посещаемость и домашние задания.  
- Обеспечить удобный интерфейс для студентов, старост и преподавателей.  
- Повысить прозрачность и эффективность учебного процесса.  
- Снизить зависимость от сторонних чатов и таблиц.

---

### ⚙️ Основные функции
| Модуль | Возможности |
|--------|--------------|
| 🗓️ **Расписание** | Просмотр своего и преподавательского расписания, создание личных событий |
| 🏠 **Домашние задания** | Назначение преподавателем или старостой, уведомления о дедлайнах |
| 🧾 **Оценки** | Просмотр результатов, история изменений |
| 👥 **Посещаемость** | Отметка присутствия, отчёты по посещаемости |
| 🔔 **Уведомления** | Push и email-уведомления о ДЗ, изменениях расписания |
| ⚡ **Администрирование** | Управление пользователями, ролями и справочниками |

### 🧩 Роли пользователей
